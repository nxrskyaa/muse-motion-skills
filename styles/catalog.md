# Style Library

Eleven opinionated visual identities. Pick **one** per video, lock it before
building (§2 of `SKILL.md`), and never ship two videos in a row with the same
look. Each sheet is a recipe: palette (six slots), typography, texture, motif
vocabulary, motion behavior, composition rules, and the style's signature
transition.

| Style | One-line | Best for |
| ----- | -------- | -------- |
| [cinematic](cinematic.md) | Kinetic type, bespoke in-world objects, camera punch | Product explainers, narratives |
| [pixel-rpg](pixel-rpg.md) | JRPG quest: dialogue boxes, HUD, chiptune | Anything frameable as a mission |
| [editorial-paper](editorial-paper.md) | Warm paper, black ink, serif, one terracotta accent | Ideas pieces, manifestos |
| [cut-paper](cut-paper.md) | Torn-paper collage, stop-motion jitter | Playful explainers, histories |
| [risograph](risograph.md) | Misregistered print layers, grain, limited inks | Zine energy, music-culture topics |
| [bauhaus](bauhaus.md) | Geometric poster: circles, bars, primary shapes | Systems, architecture, design topics |
| [ukiyoe](ukiyoe.md) | Woodblock waves, flat color bands | Journeys, flows, natural metaphors |
| [schematic](schematic.md) | Technical drawing on cream: linework, callouts | Mechanisms, how-it-works |
| [noir-halftone](noir-halftone.md) | Comic ink, halftone dots, hard shadows | Conflict, investigations, drama |
| [chalk-lecture](chalk-lecture.md) | Dark board, chalk derivations | Reasoning chains, math, "why" arguments |
| [art-deco](art-deco.md) | Gold on black, geometric luxury frames | Launches, premium announcements |

## How a sheet is written

Every sheet follows the same dimensions, so styles stay comparable and
swappable:

- **Palette** — six slots: background, surface, primary ink, secondary ink, main accent, secondary accent.
- **Typography** — the hero pairing and what it's for.
- **Texture** — the material truth of the style (grain, bleed, misregistration…).
- **Motifs** — the visual vocabulary: what objects look like here.
- **Motion** — how things move in this world (and at what frame feel).
- **Composition** — how frames are laid out.
- **Signature transition** — the one canonical way this style enters and exits.
- **Best for / Never** — where it shines, and what would break it.
